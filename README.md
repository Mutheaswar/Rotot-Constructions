# Rotot Constructions — Construction Company Website

A frontend website concept for a construction company, presenting services, projects, team information, and contact details through a structured landing page.

## Overview

Rotot Constructions demonstrates a multi-section company website using HTML, styled assets in an SCSS directory, and a JavaScript directory. The project emphasizes page layout, visual hierarchy, and presentation of service-based business content.

## Features

- Company branding and navigation bar
- About/company introduction
- Construction services overview
- Project showcase content
- Team/member information
- Testimonials and contact-oriented sections

Some navigation links and contact elements are placeholders. A functional quote-request or contact-processing backend is not included.

## Tech Stack

- **HTML5** — website markup
- **CSS3 / SCSS assets** — visual styling
- **JavaScript assets** — scripts included in the repository (their presence does not imply a specific interactive feature)
- **Google Fonts** — typography
- **Font Awesome** — icons

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Mutheaswar/Rotot-Constructions.git
   ```

2. Enter the project directory:

   ```bash
   cd Rotot-Constructions
   ```

3. Open `index.html` in a web browser, or use the VS Code **Live Server** extension.

The HTML page references `scss/style.css`. Ensure that this stylesheet is present when running the site. If you make edits to `.scss` source files, compile them to CSS before refreshing the page.

## Project Structure

```text
Rotot-Constructions/
├── index.html
├── images/
├── js/
└── scss/
```

## Current Scope

This is a frontend portfolio project, not a connected construction-management system. It does not include user authentication, a database, or server-side form submission. Any placeholder content should be replaced before using it for a real business.
